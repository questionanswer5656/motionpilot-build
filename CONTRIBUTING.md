# Contributing

Thanks for helping improve MotionPilot Core.

1. Open an issue before large changes so the intended behaviour can be discussed.
2. Keep the recognizer deterministic and independent of browser globals.
3. Add tests for new gestures, edge cases, timing, and permission behaviour.
4. Run `npm run check` with Node.js 20 or newer.
5. Describe tested browsers and physical devices in the pull request. Do not claim device coverage that was not tested.

Please keep contributions focused. Avoid adding analytics, network transmission of sensor samples, or automatic/background sensor activation.
