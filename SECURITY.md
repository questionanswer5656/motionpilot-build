# Security policy

## Supported versions

Security fixes are applied to the latest release line. This project is currently in its `0.x` early-release phase.

## Reporting a vulnerability

Please do not publish exploit details in a public issue. Use GitHub's private vulnerability reporting for this repository when available. Include the affected version, impact, and a minimal reproduction. Do not send real device recordings or other personal data unless strictly necessary and explicitly consented to.

MotionPilot Core processes sensor samples locally in the page and has no telemetry or network feature. Applications integrating this library remain responsible for protecting any data they collect or store.
